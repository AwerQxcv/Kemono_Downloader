v1.3.3 · 변경사항
  • Fix

    원본이 없는 파일은 미리보기 이미지로 다운로드

    사이트에 원본이 없고 미리보기만 남은 파일(preview_only)은 받을 수 없는 원본 주소 대신 미리보기(썸네일) 이미지로 받습니다. 이런 파일이 있으면 알림으로 알려주며, 작가 일괄 다운로드에서는 한 번만 알리고 계속 진행합니다.
  • Fix

    재시도할 파일이 오래 진행되지 않던 문제 수정

    브라우저가 다운로드를 30초 안에 시작하지 않거나(저장 위치가 NAS일 때 등), 멈춘 다운로드를 취소했는데 브라우저가 취소 완료를 알려주지 않으면 그 파일이 자리를 계속 차지해 다른 파일까지 멈추던 문제를 수정했습니다. 이제 이런 경우에도 다음 파일로 넘어가고 해당 파일은 다시 시도합니다. 또한 재시도할 파일은 따로 줄을 세워, 새 파일이 기다리는 동안에는 한 자리만 쓰도록 했습니다. 응답 없는 서버의 파일 때문에 나머지 다운로드가 느려지지 않습니다. 짧은 시간에 실패가 몰리면 서버가 요청을 감당하지 못하는 것으로 보고 15초 동안 새 다운로드를 멈췄다가 이어서 받습니다.
  • Imp

    진행 알림에 멈춘 이유 표시

    다운로드가 잠시 멈추면 진행 알림에 그 이유를 함께 보여줍니다. 대기열이 가득 차서 다음 게시글을 기다리는 중인지, 서버 과부하로 보여 잠시 쉬는 중인지(다시 시작까지 남은 시간 포함) 알 수 있습니다.
  • Imp

    다운로드 결과 알림은 직접 닫을 때까지 표시

    다운로드가 끝나거나 취소되었을 때 나오는 결과 알림은 저절로 사라지지 않고, 오른쪽 위의 × 버튼을 눌러 닫을 수 있습니다. 다른 알림에도 × 버튼이 있어 바로 닫을 수 있습니다.
v1.3.2 · 변경사항
  • New

    작가 일괄 다운로드에서 키워드로 게시글 제외

    작가 페이지에서 다운로드를 시작하면 제외할 키워드를 쉼표(,)로 구분해 입력할 수 있습니다. 제목에 키워드가 들어간 게시글(예: WIP)은 받지 않으며, 입력한 키워드는 다음에도 기본값으로 채워집니다.
  • Imp

    다운로드 중 페이지 이동

    작가 일괄 다운로드 중에도 사이트 안에서 다른 페이지로 이동할 수 있고, 진행 상황 알림도 계속 표시됩니다. 탭을 닫거나 새로고침하면 아직 시작하지 않은 게시글은 받지 않습니다.
  • Fix

    작가 일괄 다운로드 취소가 바로 적용되지 않던 문제 수정

    취소를 눌러도 이미 대기열에 들어간 파일을 끝까지 받던 문제를 수정했습니다. 이제 남은 파일과 받는 중인 파일도 함께 취소되고, 완료 대기 중에도 취소할 수 있습니다.
  • Fix

    실패한 다운로드는 뒤로 미뤄 재시도

    서버가 30초 동안 응답하지 않거나 받는 도중 1분 동안 진행되지 않는 다운로드는 취소합니다. 실패한 파일은 자리를 비워 다음 파일을 먼저 받고, 잠시 뒤 대기열 끝에서 다시 시도합니다. 원본이 사라진 파일은 기다려도 받을 수 없으므로 파일당 약 2분이 지나면 실패로 처리합니다. 정보를 불러오지 못한 게시글도 건너뛰었다가 목록 끝에서 다시 시도하고, 완료를 기다리는 동안에는 남은 파일 수를 보여줍니다.
  • Imp

    동시 다운로드 최대 5개, 이미 받은 게시글 빠르게 건너뛰기

    서버가 응답을 끊지 않도록 최대 동시 다운로드 수를 1~5로 제한했습니다(기존 0은 5로 바뀝니다). 작가 일괄 다운로드는 받을 파일이 많이 밀려 있으면 줄어들 때까지 다음 게시글을 기다리고, '확장 프로그램의 기록' 모드에서는 이미 모두 받은 게시글을 게시글 정보를 불러오지 않고 바로 건너뜁니다.
  • Imp

    다운로드 기록 저장 방식 개선

    받은 파일과 게시글 기록을 항목마다 따로 저장해, 기록이 수천 개 넘게 쌓여도 다운로드 중에 브라우저가 느려지지 않습니다. 기존 기록은 자동으로 옮겨집니다.
  • Fix

    본문 텍스트 파일을 성공 개수에서 제외

    이미지·첨부파일이 있는 게시글은 본문 텍스트 파일이 받아졌다는 이유만으로 성공이나 일부 실패로 표시되지 않습니다. 텍스트만 있는 게시글은 텍스트 파일 결과로 판단합니다.
  • Imp

    실패 알림에 서버 문제 안내 추가

    다운로드가 실패하면 확장 프로그램이 아니라 kemono / pawchive 서버 문제일 수 있다는 안내와 대처 방법을 함께 보여줍니다.
  • Imp

    게시글 다운로드 진행 상황 표시

    게시글 하나를 받을 때도 몇 개를 받았는지와 재시도 중인 파일 수를 알림으로 보여주고, 알림에서 바로 취소할 수 있습니다. 취소하는 동안에는 (작가 일괄 다운로드 포함) 정리할 파일이 몇 개 남았는지 보여줍니다.
v1.3.1 · 변경사항
  • New

    이미 받은 파일 건너뛰기

    설정에서 확장 프로그램의 기록 또는 브라우저 다운로드 기록을 기준으로 이미 받은 파일을 건너뛸 수 있습니다. 중간에 멈춘 일괄 다운로드를 처음부터 다시 받지 않아도 됩니다.
  • New

    게시글 다운로드 상태 표시

    작가 페이지의 카드 오른쪽 아래와 게시글 제목 옆에 다운로드 완료(✓), 일부 실패(⚠), 실패(✕) 여부를 표시합니다.
  • New

    다운로드 기록 내보내기 / 가져오기

    설정에서 받은 파일과 게시글 기록을 JSON 파일로 내보내거나 가져와 다른 브라우저에서도 이어서 사용할 수 있습니다.
  • Fix

    작가 일괄 다운로드가 완료 대기에서 멈추던 문제 수정

    재시도 끝에 실패한 파일이 있으면 "다운로드가 끝나기를 기다리는 중…" 표시가 사라지지 않던 문제를 수정했습니다.
  • Fix

    일부 작가 페이지에서 일괄 다운로드가 되지 않던 문제 수정

    게시글 목록의 마지막 페이지 다음을 요청할 때 오류가 나 다운로드가 시작되지 않던 문제를 수정했습니다.
v1.3.0 · 변경사항
  • New

    작가 페이지에서 전체 게시글 일괄 다운로드

    작가 페이지에서 단축키나 우클릭 메뉴를 사용하면 작가의 모든 게시글을 한 번에 다운로드합니다. 시작 전 확인 창, 진행 상황 표시와 취소 버튼을 지원하며, 서버가 요청을 제한하면 잠시 기다렸다가 다시 시도합니다.
  • New

    최대 동시 다운로드 수 설정

    설정에서 동시에 받을 파일 수를 정할 수 있습니다. 1로 두면 파일 하나가 끝난 뒤 다음 파일을 받습니다. (0 = 제한 없음)
  • Imp

    게시글 정보를 API로 가져오기

    페이지(HTML)를 읽는 대신 사이트 API로 게시글 정보를 가져와 사이트 화면이 바뀌어도 안정적으로 동작합니다. 이미지와 첨부파일은 확장자로 구분합니다.
  • Imp

    파일 서버 자동 선택

    파일마다 저장된 서버(n1, n2, file 등)와 임시 다운로드 주소를 자동으로 골라 다운로드합니다.
  • Fix

    알림 표시 오류 수정

    다른 페이지로 이동한 뒤 다운로드하면 알림이 화면 오른쪽에 글자만 붙어서 나오던 문제를 수정했습니다.
